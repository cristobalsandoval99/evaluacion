# Mercado Ñuble Digital

## Estudiante
Cristóbal Sandoval

## Descripción
Prototipo frontend en Vue 3 para dar visibilidad a productores locales y sus productos en la Región de Ñuble.

## Parte A - Estructura y navegación
Se creó la estructura modular del proyecto separando vistas (src/views) y componentes reutilizables (src/components). Se implementó la navegación SPA entre las vistas Inicio, Productos, Productores y Contacto utilizando Vue Router mediante componentes router-link.

## Tecnologías utilizadas
- Vue 3
- Vue Router 4
- Vite

## Ejecución
npm install
npm run dev
